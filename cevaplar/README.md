# Katılımcı cevapları

Kendi ad-soyad klasörünü buraya ekle: `cevaplar/Ad-Soyad/`.

Klasörün içinde açıklamalı sorguların için `log.sql` ve üç cevabın için `answers.txt` bulunmalı. Başlangıç dosyalarını [sablon/](../sablon/) klasöründen kopyalayabilirsin.

Kendi fork’una yükledikten sonra asıl projeye Pull Request gönder. Tam teslim adımları [ana sayfada](../README.md#cevaplarını-nasıl-teslim-edeceksin) yer alır. Yalnızca kendi klasörünü değiştir.
